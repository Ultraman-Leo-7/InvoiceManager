# 发票提取工具 v4

将本工具放在中国电子发票 PDF 所在文件夹，双击 `run.cmd`，生成/更新 `发票汇总.xlsx`。

## 默认输出

默认只显示三列：

- 文件名
- 项目名称
- 价税合计

## 文件夹同步

每次运行都以**当前文件夹中的 PDF**为准：

- 新增 PDF：Excel 新增对应行
- 删除 PDF：Excel 删除对应行
- PDF 内容改变：重新解析并更新
- PDF 改名但内容没变：更新文件名并复用缓存
- 未变化 PDF：直接读取隐藏缓存，不重复解析

注意：这里的“同步”是**每次运行脚本时同步**，不是后台实时监控。

## 修改显示字段

编辑 `settings.json` 的 `fields`：

```json
{
  "fields": ["文件名", "项目名称", "价税合计"]
}
```

例如想增加销售方、日期：

```json
{
  "fields": ["文件名", "开票日期", "销售方名称", "项目名称", "价税合计"]
}
```

下一次运行后，`发票汇总.xlsx` 会自动按这个列表**增加、删除并重排列**。

也可写：

```json
{
  "fields": "all"
}
```

显示全部可选字段。

## 可选字段

- 文件名
- 发票号码
- 开票日期
- 购买方名称
- 销售方名称
- 项目名称
- 价税合计
- 金额（不含税）
- 税额
- 开票人
- 提取状态

## Excel 手工修改说明

文件夹中的 PDF 是数据源。每次运行脚本都会重建汇总表，因此：

- 手工删除某一行，但 PDF 仍在文件夹：下次运行该行会恢复。
- 手工修改自动提取值：下次运行会被缓存/解析结果覆盖。
- 若希望保留人工备注，可后续增加独立的“备注/人工修正”机制。
