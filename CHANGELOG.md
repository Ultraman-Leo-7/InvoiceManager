# Changelog

All notable changes to InvoiceManager will be documented here.

## v5.2 (in development)

### Added

- New InvoiceManager branding
- QQ Mail integration for downloading JD electronic invoices
- Purchase record management
- Price-based purchase and invoice matching
- Separate matching support for product invoices and shipping fee invoices
- Automatic folder refresh
- Invoice search and sorting
- Multi-select operations with Ctrl/Shift
- Manual confirmation and notes
- Excel export

### Improved

- Better local data persistence using SQLite
- Safer storage of QQ mailbox authorization information
- Improved user documentation

## v5.1

- Introduced GUI-based invoice management
- Added PDF invoice parsing
- Added invoice table management

## Earlier versions

- Added core Chinese electronic invoice PDF extraction functionality.
