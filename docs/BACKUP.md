# InvoiceManager 数据备份与恢复

本文档说明购买记录、人工确认、备注和设置如何保存，以及坚果云备份/恢复的实际行为。

## 1. 主数据库

InvoiceManager 的长期状态保存在程序目录下：

```text
.invoice_manager.db
```

它是 SQLite 数据库，包含：

- 购买记录
- 发票解析缓存
- 人工确认
- 备注
- 显示字段设置
- QQ 邮箱地址与本地加密授权信息
- 坚果云备份设置与状态

exe 只是程序本体。正常替换或更新 exe 不会主动覆盖这个数据库。

## 2. 本地安全快照

为了减少误操作导致购买记录永久丢失的风险，以下操作执行前会先备份当前数据库：

- 编辑已有购买记录
- 删除购买记录
- 一键清空全部购买记录
- 从坚果云恢复并覆盖当前数据库

本地安全快照目录：

```text
.invoice_manager_backups/
```

默认保留最近 20 个本地快照。

如果在编辑、删除或清空购买记录前无法创建安全快照，InvoiceManager 会取消该破坏性操作。

## 3. 坚果云 WebDAV

坚果云连接使用：

- 坚果云账号邮箱
- 坚果云“第三方应用密码 / WebDAV 应用密码”

不要填写坚果云网页登录密码。

程序使用标准 WebDAV 服务地址，并在坚果云中创建：

```text
InvoiceManager/
├─ latest.db
└─ backups/
   ├─ InvoiceManager-YYYYMMDD-HHMMSS.db
   └─ ...
```

`latest.db` 是最近一次成功备份；`backups/` 中保存历史快照，程序当前保留最近约 30 个。

## 4. 自动备份

在“数据备份”窗口勾选：

```text
数据变化后自动备份到坚果云（推荐）
```

以后这些变化会触发后台备份：

- 新增/编辑/删除/清空购买记录
- 修改人工确认
- 修改发票备注
- 保存普通程序设置

自动备份不会阻塞正常界面操作。

最近成功时间和最近失败原因会保存在本地，并显示在“数据备份”窗口。

## 5. 云备份内容

云备份会包含：

- 购买记录
- 发票人工确认
- 发票备注
- 发票解析缓存
- 非敏感程序设置

不会包含：

- PDF 发票本身
- QQ 邮箱授权码
- 坚果云 WebDAV 应用密码

后两项在 Windows 上本来也使用 DPAPI 绑定本机/Windows 用户。为了让云备份更安全、更适合跨电脑恢复，创建云快照时会主动删除这两个密钥字段。

## 6. 从坚果云恢复

点击：

```text
数据备份 -> 从坚果云恢复
```

可以选择：

- 最新备份
- 某个历史时间点备份

恢复过程：

```text
下载备份
↓
SQLite integrity_check
↓
先保存当前本地数据库
↓
替换主数据库
↓
自动重启 InvoiceManager
```

如果下载文件损坏或缺少必要数据表，不会直接覆盖当前数据库。

换电脑恢复以后，需要重新输入 QQ 邮箱授权码和坚果云应用密码。

## 7. 数据可靠性边界

SQLite + 本地安全快照 + 坚果云历史备份可以显著降低单点丢失风险，但任何本地软件都不能保证绝对零风险。

建议长期使用购买记录功能时：

1. 开启坚果云自动备份。
2. 偶尔查看“最近成功备份”时间是否正常更新。
3. 不要手动删除 `.invoice_manager.db` 和 `.invoice_manager_backups/`。
4. 换电脑前先执行一次“立即备份”。
5. 如果发现异常，不要先执行“一键清空”等破坏性操作，应优先保留当前文件夹并提交问题。
