# Support

InvoiceManager is a small open-source project. Public support currently happens through GitHub Issues.

## Before opening an Issue

Please check:

1. `README.md` — quick start, complete feature reference, current limitations
2. `docs/TROUBLESHOOTING.md` — common Windows, PDF, QQ Mail and Excel problems
3. Existing GitHub Issues — the same problem may already be reported

## Bug reports

Use the **Bug 反馈** Issue form and include:

- InvoiceManager version
- Windows version
- Which module is affected
- Exact reproduction steps
- Full error text when available

Screenshots are useful, but redact all personal and invoice information first.

## Feature requests

Use the **功能建议** Issue form. Describe the workflow problem first, then the feature you would like to see.

## Security and privacy

Do not publish QQ Mail authorization codes, real invoice data, local databases, or other sensitive information in a public Issue.

For security-sensitive problems, read `SECURITY.md` and `PRIVACY.md` before reporting.
